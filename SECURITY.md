# Security Policy

`ios-dumpkit-ng` is for authorised mobile application security testing only.

Allowed use:

- Your own jailbroken test device
- Apps you own, develop, or have written permission to assess
- Test accounts and controlled environments
- Internal security review, penetration testing, and bug bounty work within scope

Disallowed use:

- Unauthorised app dumping or piracy
- Credential theft or bulk extraction of user data
- Stealth, persistence, malware, or evasion features
- Bypassing device ownership controls
- Testing outside a written scope

The tool does not hardcode passwords and redacts sensitive log messages. Do not include passwords, tokens, or private customer data in issue reports.

Report security issues privately to the project maintainers.
